# Product Guide: HyprQur'an

## Vision
HyprQur'an is a modern, Wayland-native desktop application designed to provide a fast, beautiful, and distraction-free Qur'an reading experience for Linux users. Built with Rust and GTK4, it prioritizes performance, native integration, and ease of use.

## Core Purpose
To offer a lightweight and keyboard-friendly Qur'an reader that adheres to modern Linux desktop standards, specifically targeting the Wayland display protocol.

## Target Audience
- Linux desktop users, particularly those on Wayland-based compositors (like Hyprland, Sway, GNOME).
- Individuals looking for a minimalist, non-web-based Qur'an reading tool.
- Users who value keyboard-driven workflows and customization.

## Key Features
- **Authentic Arabic Text:** High-quality rendering of the Qur'an text (using the "Amiri Quran" font).
- **Translation Integration:** Side-by-side display of translations (English, Indonesian, and others).
- **Modern UI/UX:** Responsive GTK4 interface with native light/dark theme support.
- **Customization:** Dynamic font size adjustment to suit different screens and preferences.
- **Efficient Navigation:** Full keyboard shortcut support for a distraction-free experience.
- **Bookmarking:** A dedicated system to save and return to specific verses (Ayahs).

## High-Level Roadmap
- **Content Expansion:** Load and index all 114 Surahs (Completed).
- **Reliability:** Fix the bookmarking persistence bug.
- **Packaging:** Streamline distribution for various Linux distributions (AUR, Flatpak).
